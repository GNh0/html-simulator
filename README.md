표 복사:
 1. HTML을 적용한 뒤 Preview에서 복사할 셀 범위를 드래그로 선택합니다.
 2. `Ctrl+C` 또는 `아마란스 복사`로 실제 그룹웨어와 같은 형식으로 복사한 뒤 MA100100에 `Ctrl+V`로 붙여넣습니다. 기존 `Ctrl+Shift+C`도 같은 동작입니다.
 3. 각 셀의 값 다음에 빈 줄을 넣습니다. 순번, 품명, 규격, 수량, 단위, 구매처, 납기요청일, 용도, 단품도번, 비고의 10열 전체를 선택하면 한 행이 20줄로 복사됩니다. 빈 규격/날짜/도번/비고도 위치를 유지합니다.
    엑셀 등에 행/열 그대로 붙여넣을 때는 `표 복사` 버튼을 사용합니다.
 4. 셀을 더블클릭해 편집하는 동안에는 기존 텍스트 복사를 사용합니다. 셀 안의 줄바꿈은 표 복사 시 공백으로 바뀝니다.

`HTML` 버튼은 기존과 같이 HTML 소스를 복사합니다.
