표 복사:
 1. HTML을 적용한 뒤 Preview에서 복사할 셀 범위를 드래그로 선택합니다.
 2. `표 복사` 또는 `Ctrl+C`로 선택한 값을 행/열 형태로 복사합니다.
 3. MA100100에 붙여넣을 때는 `아마란스 복사` 또는 `Ctrl+Shift+C`를 사용합니다. 각 항목 사이에 빈 값을 넣습니다.
    순번, 품명, 규격, 수량, 단위, 구매처, 납기요청일, 용도, 단품도번, 비고의 10열 전체를 선택하면 19개 값으로 복사됩니다. 빈 날짜/비고도 위치를 유지합니다.
 4. 셀을 더블클릭해 편집하는 동안에는 기존 텍스트 복사를 사용합니다. 셀 안의 줄바꿈은 표 복사 시 공백으로 바뀝니다.

`HTML` 버튼은 기존과 같이 HTML 소스를 복사합니다.
